# 模型 Loading 视觉调整设计

## 目标

优化模型拖入画布时的 Loading 展示：移除 HUD 动画自带的浅绿色方形背景，并适度放大动画，使其在深色画布上更清晰。

## 调整范围

- 删除 `hud-spinner.svg` 根节点上的绿色背景样式，使 SVG 背景完全透明。
- 将编辑器画布中的 HUD 动画显示尺寸从 `80 × 80px` 调整为 `96 × 96px`。
- 保持全画布深色遮罩、居中布局、提示文字和加载状态逻辑不变。
- 不修改 Runtime 页面及其他 Loading 组件。

## 验收标准

1. 模型加载时，HUD 动画周围不再出现浅绿色方块。
2. HUD 动画显示尺寸为 `96 × 96px`，且保持居中、不变形。
3. “模型加载中...”文字和画布遮罩视觉保持不变。
4. 编辑器现有测试、样式检查、类型检查和生产构建通过。

## 验证方式

- 自动检查 SVG 根节点不再包含背景声明。
- 自动检查 Loading 图片样式尺寸为 `96px`。
- 在编辑器中触发模型加载状态，进行视觉确认。
