# 编辑器场景加载遮罩设计

## 目标

打开、切换或重新加载场景时，在中央三维画布上持续显示加载反馈，直到场景文档获取完成且 Three.js 画布已完成资源下载、解析和实例化。

## 方案

- 复用模型拖拽加载遮罩的 `/loading/hud-spinner.svg`、居中布局和画布范围，不新增视觉资源。
- `EditorWorkspace` 将文档 Store 的 `loading` 状态传入 `EditorCanvas`，覆盖场景接口请求阶段。
- `EditorCanvas` 在 `engine.initialize()` 和每次 `engine.loadDocument()` 期间维护内部加载状态，覆盖实际画布与模型资源就绪阶段。
- 画布任一场景加载状态或现有模型添加状态为真时显示遮罩。场景加载优先显示“场景加载中...”，单独添加模型时保持“模型加载中...”。

## 异常与并发

- 场景接口或引擎加载失败时关闭 loading，并保留现有错误状态展示。
- 快速切换场景时，只有最新 `loadGeneration` 对应的引擎请求可关闭 loading，迟到的旧请求不能提前隐藏新场景遮罩。
- 场景加载与拖拽模型同时发生时，任一状态未完成都保持遮罩。

## 验收标准

1. 场景文档请求开始后，画布显示现有 HUD SVG 和“场景加载中...”。
2. Three 引擎仍在加载场景资源时，即使文档接口已返回，遮罩也不提前关闭。
3. 当前场景加载成功或失败后关闭场景 loading。
4. 快速切换场景时，旧请求完成不会影响新请求遮罩。
5. 原有拖拽和双击添加模型的 loading 行为不变。
